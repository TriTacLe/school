## IMAT3012 Matematikk for ingeniørfag 3 B
NTNU, høst 2026, 7,5 studiepoeng. Flerdimensjonal integrasjon, vektorfelt og partielle differensiallikninger.
## Vurdering
- Vurderingsordning: Skriftlig skoleeksamen, 100 prosent.
- Obligatorisk: Obligatoriske oppgaver. Noen øvinger kan godkjennes muntlig.
- Undervisningsform: Forelesninger, øvingsoppgaver, obligatoriske oppgaver.
## Innhold
- Integrasjon: dobbel- og trippelintegral i ulike koordinatsystem, flate- og linjeintegral, numeriske metoder, masse- og momentberegning.
- Vektorfelt: divergens, curl, konservative felt og potensial, arbeid, sirkulasjon, fluks, Greens teorem, Stokes' teorem, divergensteoremet.
- Partielle differensiallikninger: bevaringslover og endelig volum-metoder med beregningsverktøy.
