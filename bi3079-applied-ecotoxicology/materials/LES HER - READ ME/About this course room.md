## About this course room
Kilde: Canvas, BI3079, modul "LES HER / READ ME"

This course room is set up with a standard course design that applies to all NTNU courses. As the course coordinator, you can adjust the settings and decide which tools your students will have access to.

Home is the start page of the course room. Here you will find the module overview, and this is also where the latest announcements will be published.

We recommend that you add information about the course, the learning outcomes, and contact information in the free-text field in **Syllabus ***(Emneoversikt)*. Guidance on how to do this can be found on the [**Syllabus** page](https://ntnu.instructure.com/courses/26218/assignments/syllabus).

In **Files **you will find a folder containing NTNU graphics and icons that can be used if you wish to build your pages with visual elements.

The course Canvas for Learning provides useful information on how to use the functions in Canvas and how to structure your course. You will find it on your Dashboard.

If you need assistance, you can use the Help button in the menu on the left. Here you will find support guides, and you can submit requests via NTNU Help. You can also get user support from the Orakel Service.

Important: Do not publish this module. You may delete the entire module before students gain access to the course room if you wish.
