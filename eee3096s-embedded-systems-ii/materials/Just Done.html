GA-5 Conceptual Assignment

The GA-5 Conceptual Assignment is starting this week (from 25 Aug). But you don't need to submit code or other implementation aspects for this assignment. It is, you could say, more thought experiments and being able to demonstrating logical thinking and awareness of development methods and tools.

So, the nice thing about the Conceptual Assignment is not developing and submitting implementation artefacts. However, the perhaps not so nice, thing is the GA-5 Test, which is a paper-based test you answer individually in a testing venue.
