Assessment Strategy

Duly Performed Requirements

The following course DP rules apply:

  • Completion and submission of all practicals

  • Completion of the course project (Computer Science students only)

  • NOTE: The DP Requirements for this course are specified in the course handout (the information here may be out of date, the course handout provides the latest version of the DP rules and assessment involved.

Course Assessment

The assessment procedure for this course is based on the following:

  1. Class Test

  2. Practicals

  3. Hackathon

  4. Course project (for EEE3095S only)

  5. Final examination 

Note while there may be two class test dates sheduled for this course, this is proivided as a redundance incase it is preferred to swap the test dates, e.g. due to problems of holiding the first test or if the class decides they would prefer the second date for the test instead of the first date listed. If you are absent for the class test (i.e., ill or unable to attend for other reasons) then your marks weighting for the class test is automatically transferred to the final exam. 

The marks breakdown for these assessments are shown in the course handout.

Gradescope will be used for submitting assignments and for releasing marks.
