# EEE3096S Embedded Systems II

UCT, second semester 2026. STM32 (F051 and F446), ARM AArch32 assembly, CubeIDE + HAL.

## Map

- [[Troubleshooting]] - CubeIDE build error fixes and firmware conflict notes
- `lectures/` - L01 to L19 slides (pdf, some pptx)
  - `code/L08/` - assembly examples from lecture 8
  - `code/timing/` - timing helpers (tictoc timer, microsecond measurement, wrap handling)
- `arm-reference/` - ARM assembly quick references and full instruction set
- `datasheets/` - STM32F051, STM32F446, Cortex-M0, ARMv6-M, HAL library
- `pracs/` - practical briefs, planning docs, group list
  - [[Prac 1A demo guide]] - run order, talking points and tutor Q&A for the 1A demo
  - `code/P1/` - prac 1 starter code
  - `report-template/` - IEEE report template (docx + latex)
- `materials/` - course handouts (3096S and 3095S), 2025 course notes, exam advice, CubeIDE setup, I2C app note
- `attachments/` - screenshots embedded in Troubleshooting

## Conventions

- Lecture slides named `LNN Title.pdf` matching course numbering
- Prac briefs keep course labels (P01, P2, Prac 1A)
- Datasheets named `Chip Document type.pdf`
