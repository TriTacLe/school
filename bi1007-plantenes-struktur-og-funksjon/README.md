## BI1007 Plantenes struktur og funksjon

NTNU, høst 2026, 7,5 studiepoeng. Karplanters anatomi og fysiologi, inkludert celle-, vev- og organ-typer; primær og sekundær vekst; anatomiske tilpasninger til ulike miljøer; fotosyntese; vannrelasjoner og intern transport; mineralnæring og toksisitet; regulering av vekst og utvikling; respons på lys, gravitasjon, og andre miljøfak...
