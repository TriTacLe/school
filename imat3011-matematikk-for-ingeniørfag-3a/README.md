# IMAT3011 Matematikk for ingeniørfag 3 A

NTNU, høsten 2025. Numerikk, lineær algebra og optimering. Kurset bruker ikke Blackboard; alt ligger på [wiki-siden](https://wiki.math.ntnu.no/imax3011/2025h/start).

## Kart

- `lecture-notes/` - Trondheim-forelesningene 1 til 28 (14 utgikk)
- `extra-notes/`
  - `gjovik/` - temanotater og slides fra Gjøvik-parallellen
  - `alesund/` - kapittelnotater fra Ålesund-parallellen
- `exams/` - IMAx3011 2024 til 2026 med LF, pluss forløperne IMAx2150 og TDAT2002 tilbake til 2017
- `code/` - Jupyter-notatbøker (fikspunkt, Jacobi/Gauss-Seidel)
- `materials/` - formelark, Rivertz-kompendium, vektorromsaksiomene

## Ikke nedlastbart
