## Tool for Learning Geometric Transformations
Kilde: Canvas, TDT4195, modul "Tool for Learning Transformations"

Geometric Transformations are useful in Visual Computing, as well as in other areas such as Robotics.

However, much practice is usually necessary to get acquainted with them.

In 2025, Jesper Norsted, a master student at IDI, created a tool for practising with transformations in a fun way.

You can find his tool here: [https://jesper2k.github.io/SkewX/](https://jesper2k.github.io/SkewX/)
