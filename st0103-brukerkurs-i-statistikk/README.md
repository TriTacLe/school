## ST0103 Brukerkurs i statistikk

NTNU, høst 2026, 7,5 studiepoeng. Deskriptiv statistikk. Sannsynlighetsregning, herunder regneregler for sannsynlighet, betinget sannsynlighet og uavhengighet, tilfeldige variabler, diskrete og kontinuerlige sannsynlighetsfordelinger, forventningsverdi, varians, todimensjonale sannsynlighetsfordelinger, kovarians og korrelasjon.
